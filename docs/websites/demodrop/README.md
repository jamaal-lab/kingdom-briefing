# DemoDrop version of the /websites page

Live: https://btbs-websites.ddsites.co (DemoDrop site `st_d5f06b42db5a4b82`, mode active, no custom domain).

Hand-built for DemoDrop's format: one self-contained HTML page (`index.html`) plus two fictional
Atelier North pages for the before/after slider (`before.html`, `after.html`). Images were imported to
the site with `add_image` from the owner's public sites (logo from bridge2bettersolutions.com; hero,
devices, portrait and 8 concept images from bridgeweb.lovable.app). The published index has one
later edit (heading letter-spacing) applied on DemoDrop.

The project intake is a `data-dd-form="Project Intake"` form: DemoDrop stores each submission and
emails the agency owner. Branching, validation, review and draft-saving run in the page script;
answers from skipped steps are disabled so they are not submitted.
